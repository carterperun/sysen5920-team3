TEAM 3 XRP ROVER — CONTROLS

Competition supervisor main_code.py · one program, one controller, everything below

⚠ ALL-STOP — WORKS FROM ANY MODE

  • START or SELECT — instant stop, back to menu
  • HOLD the USER button on the robot ~1 s — hardware stop, works even if Bluetooth is dead
  • Controller turned off / app frozen for 1.5 s during any autonomous run — robot stops itself
Every all-stop lands on the blinking-pink MENU with motors off, and logs which trigger fired.

Status Light — what the RGB LED means

LightPatternMeaning
Pink, blinking MENU — parked & safe, waiting for a mode pick
Green, solid MANUAL — sticks are live
Red, fast flash TURBO ON in manual — full speed cap, drive carefully
White, fast flash REVERSE-DRIVE ON in manual — sticks inverted, rover drives tail-first (shows even if turbo is also on)
Cyan, solid AUTONOMOUS RUNNING (challenge or D-pad assist) — hands off the robot!
Orange, blinking NO CONTROLLER — motors stopped, waiting for PestoLink to (re)connect
Red, solid (~1–3 s) PROBLEM — at boot: log file broken (flash full/corrupt) · after a crash: error logged, returning to menu · in sumo: motors not moving (check power switch / battery)
Blue, solid Standalone test scripts only: connected & armed, waiting for launch button

MENU · blinking pink

A
Enter MANUAL driving mode
B
Launch LINE FOLLOWER (line_track.py — simple tracker, no calibration) Place the robot straddling the line FIRST — the B press is the start (light goes cyan). Stops itself when the line ends; START stops it anytime.
X
Launch SUMO Place the robot near the RING CENTER first — the X press is the start. It first SURVEYS the ring (straight to the line, back, 180°, across to the far line) to set Home at the true center, then hunts blocks. A geo-fence keeps every move inside the circle.
Y
Launch MAZE (maze_solver.py — right-wall follower) Place the robot in the START cell facing NORTH (toward the goal end) first — the Y press is the start. Turns lock to compass headings so 90°s can't drift.
D-Pad ↑
Launch AUTO SMASH TOWER (tower_smash_auto.py) Point the robot AT THE TOWER first. It ranges the tower, charges through it +20 cm at high speed, backs up to the tower spot, then does three 90° clearing sweeps.
any button
Button spy: every press in the menu logs its index to main_log.txt Use it to verify what your controller calls START, triggers, D-pad…

MANUAL · solid green · red flash = turbo

L-Stick ↑↓
Throttle (forward / reverse)
R-Stick ←→
Steering
B
TURBO toggle — speed cap 0.8 → 1.0, light flashes red fast Press again to return to normal. Always starts OFF when entering manual. (B launches the line follower only from the MENU — no conflict.)
X
REVERSE-DRIVE toggle — light flashes white, sticks invert to drive tail-first intuitively Stick-forward backs up, stick-right swings the tail right. Press X again for normal. Starts OFF on entering manual; D-pad assists stay nose-relative.
LEFT TRIGGER
Jog paddle FORWARD — hold to move; ~1.5 s of holding covers the full travel Safety-clamped at the end stops (10–190°); servo power cuts 1 s after release so it can't burn out. Works during D-pad auto-forward too.
RIGHT TRIGGER
Jog paddle BACK — hold to move, same speed and safety clamps
D-Pad ↑
Auto-drive forward 100 cm (cyan light) Holds heading with the IMU; stops early if the rangefinder sees an obstacle within 15 cm.
D-Pad ←
Rotate 90° left (cyan light)
D-Pad →
Rotate 90° right (cyan light)
D-Pad ↓
Rotate 180° (cyan light)
